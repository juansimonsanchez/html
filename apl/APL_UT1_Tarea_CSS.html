1. DESCRIPCIÓN GENERAL. OBJETIVOS 📖 ¶

Un esqueleto HTML plano no transmite el rigor ni la confianza necesarios en un entorno corporativo. El diseño visual, la correcta alineación de capas y la legibilidad de logs o tablas de subredes son habilidades fundamentales para cualquier técnico de sistemas.

El objetivo de esta tarea es aprender a diseñar interfaces profesionales mediante un proceso andamiado y altamente guiado. El alumno experimentará primero con estilos de fuentes, colores y bordes en tres hojas independientes. Posteriormente, analizará los diferentes layouts y colocaciones de las etiquetas semánticas y la inserción de imágenes en columnas. Para concluir, conservará un backup de sus pruebas y consolidará el portal web en una única hoja de estilos coherente y validada, profundizando de manera práctica en la precedencia y la cascada de CSS3.

2. CONSIDERACIONES PREVIAS 📖 ¶

  • Rutas Relativas Obligatorias: Todo elemento enlazado (CSS, imágenes) debe llamarse con rutas relativas.

  • No Modificar los ID en Formularios: Respeta los selectores e identificadores creados en la unidad de HTML para asegurar que las etiquetas <label> permanezcan unidas visualmente a sus respectivos <input>.

  • Validación: Cada documento HTML creado debe validarse con Firefox sin presentar ningún error de marcado estructural.

  • Originalidad: Se proporciona un documento para ver el posible resultado, pero los títulos, textos deben ser originales e imágenes se tienen que personalizar, NO pueden ser los mismos. Vuestro nombre debe de aparecer en el pie de página

  • Previsualización: Se facilitarán documentos pdf para previsualizar una posible solución.

Asegúrate de que los colores sean legibles y coherentes. Usa el siguiente bloque de código como base, modificando los colores en index.css, servicios.css y contacto.css para que cada página tenga una identidad visual única.
