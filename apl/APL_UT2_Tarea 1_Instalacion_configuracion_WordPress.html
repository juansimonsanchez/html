1. DESCRIPCIÓN GENERAL. OBJETIVOS ¶

El propósito central de esta práctica es que el alumno aprenda a desplegar, configurar y verificar de extremo a extremo un Gestor de Contenidos (CMS) de referencia industrial como WordPress en un entorno de infraestructura real de producción.

El alumno preparará el entorno de servidor web, descargará los archivos del núcleo de la aplicación mediante la consola de comandos de Linux, gestionará las rutas del sistema de archivos de Apache y completará el proceso de instalación a través de la interfaz gráfica web conectándolo con el motor de base de datos MySQL/MariaDB.

2. CONSIDERACIONES PREVIAS ¶

Antes de iniciar los bloques prácticos de comandos, el alumno debe verificar el cumplimiento del siguiente ecosistema de infraestructura:

  1. Instancia Cloud Operativa: Tener acceso SSH activo a su máquina virtual Linux desplegada sobre la plataforma OpenStack del centro educativo.

  2. Direccionamiento e IP Flotante: Disponer de una dirección IP Flotante pública asociada a la instancia y comprobar que los grupos de seguridad del firewall de OpenStack permiten el tráfico entrante en el puerto TCP 80 (HTTP).

  3. Servicio LAMP Activo: Asegurarse de que el servidor web Apache, el motor de bases de datos MySQL/MariaDB y el intérprete de PHP (Stack LAMP) se encuentran en ejecución

Debemos preparar el entorno necesario para poder instalar el CMS que vamos a utilizar. Necesitamos:

  • Servidor Web (Apache)

  • Sistema Gestor de Base de datos (MySQL o MariaDB)

  • PHP

Para configurar el hosting en Linux será necesario instalar y configurar las aplicaciones anteriores.

La manera más sencilla es a través de la instalación y configuración de XAMPP, un paquete que instala todo lo anterior. Nosotros ya lo hicimos al montar nuestro servidor Apache. Ya se instalaron todas las librerías y paquetes necesarios.

Paso 3: Creación de la Base de datos

Para configurar WordPress, necesitamos crear una base de datos en MySQL. Vamos a crearla. Entramos en la consola de MySQL y ejecutamos unas sentencias SQL.

sudo mysql -u root

Está marcado en negrita lo que se tiene que introducir, así como los mensajes que salen al introducirlos. IMPORTANTE: Donde aparece <your-password> cambiarlo por la contraseña de vuestra elección sin poner los signos < y >. Vuestra contraseña entre comillas simples. No copies. Los “;” son importantes al final de cada sentencia.

CREATE DATABASE wordpress;
CREATE USER wordpress@localhost IDENTIFIED BY
'<your-password>';
GRANT SELECT,INSERT,UPDATE,DELETE,CREATE,DROP,ALTER
ON wordpress.*
TO wordpress@localhost;
FLUSH PRIVILEGES;
QUIT;

Hacer capturas de la ejecución de esos comandos.

Reiniciamos MySQL con:

sudo systemctl restart mysql

Coloca los archivos de WordPress en la ubicación deseada en tu servidor web:

  1. Si quieres integrar WordPress en la raíz de tu dominio (ej. http://example.com/) mueve o sube los contenidos de la carpeta donde WordPress fue extraído a la carpeta raíz de tu servidor web.

  2. Si quieres que la instalación tenga su propia subcarpeta en tu sitio web (ej. http://example.com/blog/) renombra la carpeta wordpress al nombre que desees y muévelo o súbelo a tu servidor web. Como ejemplo, si quieres tu instalación en la carpeta llamada "blog" deberás renombrar la carpeta "wordpress" a "blog" y subirla a la carpeta raíz de tu servidor web. Nosotros vamos a hacer esto, pero con la carpeta “iescelia”.
