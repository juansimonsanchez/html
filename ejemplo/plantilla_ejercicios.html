Ejercicio 1. Definición de esquema y restricciones Básico

Crea una base de datos llamada gestion_curso con juego de caracteres utf8mb4 y las siguientes tablas:

  • modulos: id_modulo (INT, PK, AUTO_INCREMENT), nombre (VARCHAR(80), NOT NULL), horas (INT, mayor que 0).

Ejercicio 2. Automatización mediante script Python Intermedio

Desarrolla un programa que lea un listado de notas, calcule la media aritmética y muestre un aviso si algún valor está fuera del rango [0, 10].

  1. Solicita al usuario las calificaciones separadas por comas.
  2. Valida que cada entrada sea numérica y esté comprendida entre 0 y 10.
  3. Muestra la nota media redondeada a dos decimales y el número total de aprobados.
ejercicio2_notas.py 
#!/usr/bin/env python3
def calcular_media(notas):
    if not notas:
        return 0.0
    return round(sum(notas) / len(notas), 2)

4. Cuestiones Teóricas y Test de Repaso ¶

4. Cuestiones Teóricas y Test de Repaso

Responde razonadamente a las siguientes cuestiones breves antes de entregar la práctica:

  1. ¿Qué diferencia existe entre una restricción UNIQUE y una PRIMARY KEY?
  2. ¿Por qué conviene usar utf8mb4 en lugar de utf8mb3 en bases de datos modernas?
  3. ¿Qué ocurre al eliminar un registro padre cuando una clave ajena tiene ON DELETE CASCADE frente a ON DELETE RESTRICT?
Comprobar respuestas clave de autoevaluación
  • Pregunta 1: PRIMARY KEY no admite valores NULL y solo puede haber una por tabla; UNIQUE sí puede admitir NULL y pueden existir varias.
  • Pregunta 2: utf8mb4 soporta caracteres Unicode completos de hasta 4 bytes (incluidos emojis y símbolos extendidos).
  • Pregunta 3: CASCADE elimina automáticamente las filas hijas dependientes; RESTRICT impide el borrado si existen filas hijas asociadas.
