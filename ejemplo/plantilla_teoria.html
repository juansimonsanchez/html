⚠️ Aviso crítico (.alert-callout): Utiliza este bloque rojo para advertencias importantes, errores frecuentes en producción o precauciones de seguridad.

3. Bloques de Código y Detección Automática ¶

3. Bloques de Código y Detección Automática

script.js envuelve automáticamente cada <pre><code> dentro de .code-wrapper, detecta el lenguaje y añade los botones de Copiar y Descargar según el tipo de contenido.

3.1. SQL (auto-detectado .sql con descarga)

-- Ejemplo de consulta DDL/DML en MySQL
CREATE DATABASE IF NOT EXISTS academia
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;

SELECT nombre, email
FROM alumnos
WHERE activo = 1
ORDER BY nombre ASC;

3.2. Python (auto-detectado .py con descarga)

#!/usr/bin/env python3
def comprobar_servicio(nombre, puerto=80):
    print(f"Verificando {nombre} en el puerto {puerto}...")
    return True

if __name__ == "__main__":
    comprobar_servicio("nginx", 443)

3.3. Script Bash completo (auto-detectado .sh con descarga)

#!/bin/bash
set -euo pipefail
echo "Iniciando copia de seguridad..."
tar -czf backup_$(date +%F).tar.gz /etc/nginx
