Introducción: Arrays Tradicionales vs. Colecciones en Python

Limitaciones de los arreglos estáticos frente a las estructuras dinámicas nativas

En muchos lenguajes de programación tradicionales (como C o Java básico) se implementan los arrays (o arreglos), estructuras que almacenan elementos bajo un nombre común. Sin embargo, los arrays tradicionales presentan dos grandes limitaciones:

⚠️ Arrays Tradicionales

  • Homogéneos: Solo permiten guardar datos del mismo tipo (todos enteros o todos texto).
  • Estáticos: Al declararse se debe indicar su tamaño fijo y su longitud no puede modificarse en tiempo de ejecución.

🐍 Colecciones Nativas en Python

  • Heterogéneas: Permiten mezclar distintos tipos de datos (int, str, bool, otras listas...).
  • Dinámicas: Crecen o decrecen automáticamente en memoria al añadir o eliminar elementos (list, dict).

El Tipo de Dato LISTA (list)

Construcción, indexación, slicing, mutabilidad, copia segura, métodos y matrices

2.1 Construcción, Declaración e Indexación

Las listas se declaran entre corchetes []. Sus posiciones empiezan en 0 y admiten índices negativos desde el final (-1 es el último elemento).

listas_construccion_indexacion.py 
# Ejemplos de declaración de listas
lista_vacia = []
enteros = [1, 4, 56, 78, 100]
decimales = [1.4, 4, 56.5, 78, 100.3]
cadenas = ['hola', 'adios', 'buena suerte']
mixta = ["a", 1, True]
inicializada = [0, 0, 0, 0, 0, 0]

# Indexación y acceso
loteria = [3, 32, 12, 21, 16, 33]
print(loteria[0])   # Muestra 3 (primer elemento)
print(loteria[5])   # Muestra 33 (último elemento)
print(loteria[-1])  # Muestra 33 (índice negativo)

# ERROR DE ÍNDICE:
# print(loteria[6]) -> IndexError: list index out of range
# loteria[6] = 99   -> IndexError: no se puede expandir asignando a índice inexistente

2.2 Operaciones Básicas, Slicing y Funciones Globales

operaciones_slicing.py 
lista = [1, 2, 3, 4, 5, 6]
letras = ["a", "b", "c", "d", "e"]

# Recorrido múltiple simultáneo con zip()
for num, letra in zip(lista, letras):
    print(num, letra)  # 1 a / 2 b / 3 c / 4 d / 5 e

# Pertenencia, concatenación y repetición
print(2 in lista)        # True
print(8 not in lista)    # True
print(lista + [7, 8])    # [1, 2, 3, 4, 5, 6, 7, 8]
print([0, 1] * 2)        # [0, 1, 0, 1]

# Slicing / Rebanadas: lista[inicio:fin:paso] (fin no incluido)
print(lista[2:4])        # [3, 4]
print(lista[1:4:2])      # [2, 4]
print(lista[:5])         # [1, 2, 3, 4, 5]
print(lista[5:])         # [6]
print(lista[::-1])       # [6, 5, 4, 3, 2, 1] (invierte la lista)

# Funciones globales predefinidas
nums = [20, 40, 10, 40, 50]
print(len(nums), max(nums), min(nums), sum(nums))  # 5, 50, 10, 160
print(sorted(nums))                # [10, 20, 40, 40, 50] (NO modifica original)
print(sorted(nums, reverse=True))  # [50, 40, 40, 20, 10]

2.3 Mutabilidad, Copia Segura ([:]), Métodos y Matrices

mutabilidad_metodos_matrices.py 
# ALIAS vs CLONADO EN MEMORIA
lista1 = [1, 2, 3]
alias = lista1        # Apuntan al MISMO objeto en memoria
copia = lista1[:]     # Crea una nueva lista independiente
lista1[1] = 99
del lista1[2]         # Borra el elemento en índice 2 con 'del'
print(alias)          # [1, 99] -> ¡Cambia también!
print(copia)          # [1, 2, 3] -> Intacta

# MÉTODOS PROPIOS (modifican in-place)
valores = [1, 2, 3, 4, 5]
valores.append(6)         # Añade 6 al final -> [1, 2, 3, 4, 5, 6]
valores.extend([7, 8])    # Une otra lista al final
valores.insert(1, 12)     # Inserta 12 en índice 1
eliminado = valores.pop() # Extrae y devuelve el último (8); pop(0) saca el primero
valores.remove(12)        # Elimina la primera aparición del valor 12
valores.reverse()         # Invierte la lista en el lugar
valores.sort()            # Ordena de menor a mayor (sort(reverse=True) descendente)
print(valores.count(5))   # Veces que aparece el 5
print(valores.index(5))   # Índice de primera aparición (ValueError si no existe)

# LISTAS MULTIDIMENSIONALES (Matriz 3x3)
tabla = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
print(tabla[1][1])        # Fila 1, Columna 1 -> 5

El Tipo de Dato TUPLA (tuple)

Colecciones ordenadas inmutables, TypeError y métodos de búsqueda

Las tuplas cumplen el mismo propósito conceptual que las listas (colecciones ordenadas de datos repetibles y heterogéneos), con la diferencia clave de que son inmutables: una vez creadas con paréntesis (), no se puede alterar su tamaño ni modificar sus elementos.

tuplas_inmutabilidad.py 
# Construcción de tuplas
tupla_vacia = ()
tupla_heterogenea = ("a", 1, True)
tupla_un_elemento = (42,)  # ¡La coma final es obligatoria para que sea tupla!

# Operaciones permitidas (lectura, slicing, concatenación, funciones globales)
t = (1, 2, 3, 4, 1, 2, 3)
print(t[1:4])          # (2, 3, 4)
print(len(t), max(t))  # 7, 4
print(3 in t)          # True

# Métodos exclusivos de búsqueda (al no poder modificarse)
print(t.count(1))      # 2 (número de apariciones)
print(t.index(2))      # 1 (primera aparición)
print(t.index(2, 2))   # 5 (busca a partir de la posición 2)

# DEMOSTRACIÓN DE INMUTABILIDAD:
# t[1] = 5  --> TypeError: 'tuple' object does not support item assignment

El Tipo de Dato MAPA / DICCIONARIO (dict)

Pares clave-valor, acceso seguro con .get(), .copy() y recorridos

Los diccionarios almacenan parejas de clave-valor delimitadas por llaves {}. Son estructuras mutables donde los valores se recuperan directamente mediante su clave única en lugar de un índice numérico.

diccionarios.py 
# Creación directa y progresiva
diccionario = {'one': 1, 'two': 2, 'three': 3}
dict1 = {}
dict1["one"] = 1

# Operaciones básicas
print(len(diccionario))     # 3 (número de pares clave-valor)
print(diccionario["one"])   # 1 (si no existe la clave -> KeyError)
print("two" in diccionario) # True (comprueba existencia de CLAVE)
del diccionario["one"]      # Elimina la clave "one" y su valor

# Copia independiente con .copy() (evita alias con =)
copia_segura = diccionario.copy()

# Métodos principales
diccionario.update({'four': 4, 'five': 5})    # Agrega o actualiza claves
print(diccionario.get("two"))                 # 2
print(diccionario.get("diez", "no existe"))   # 'no existe' (sin lanzar KeyError)
valor = diccionario.pop("two", "no existe")   # Extrae y devuelve el valor; borra la clave
# diccionario.clear()                         # Vacía por completo el diccionario -> {}

# Recorridos fundamentales
for clave in diccionario.keys():
    print("Clave:", clave)

for valor in diccionario.values():
    print("Valor:", valor)

for clave, valor in diccionario.items():
    print(f"{clave} -> {valor}")

Cadenas de Caracteres (str) y sus Operaciones

Secuencias inmutables, conversión str(), búsqueda, reemplazo y split()

En Python, las cadenas (str) se comportan como secuencias inmutables de caracteres (similares a tuplas de caracteres), indexadas desde 0 hasta len(cadena) - 1.

cadenas_operaciones.py 
cadena = "Hola mundo"
print(len(cadena))   # 10 (incluye el espacio)
print(cadena[2])     # 'l'

# Concatenación y conversión obligatoria con str()
precio = 34
mensaje = "El precio del producto sería " + str(precio) + " euros"

# Métodos principales de transformación
print(cadena.upper())        # "HOLA MUNDO"
print(cadena.lower())        # "hola mundo"
print("python".capitalize()) # "Python"

# Búsqueda y reemplazo
print(cadena.find("mundo"))             # 5 (índice de inicio)
print(cadena.find("mondo"))             # -1 (no encontrado)
print(cadena.replace("Hola", "Ostras")) # "Ostras mundo"

# Segmentación: Slicing y split()
print(cadena[1:7])          # "ola mu"
print(cadena.split())       # ['Hola', 'mundo'] (devuelve una lista)

Manejo de Errores y Excepciones

Errores sintácticos vs. tiempo de ejecución y bloque try - except - else - finally

1. Errores Sintácticos (SyntaxError)

El código está mal escrito formalmente y el intérprete no puede ni siquiera iniciar el programa.

while True print('Hola') # Faltan los ':'

2. Excepciones en Ejecución

Ocurren mientras el programa se ejecuta. Si no se capturan, detienen la ejecución:

  • ZeroDivisionError: 4 / 0
  • NameError: variable no definida
  • TypeError: "2" + 2
  • ValueError: int("abc")
control_excepciones.py 
# Estructura completa: try - except - else - finally
try:
    cad = input("Introduce un divisor: ")
    resultado = 10 / int(cad)
except ValueError:
    print("Error: No se puede convertir a entero.")
except ZeroDivisionError:
    print("Error: No se puede dividir por cero.")
except Exception as e:
    print(f"Otro error inesperado: {e}")
else:
    # Se ejecuta SOLO si el bloque 'try' terminó sin errores
    print(f"Cálculo exitoso. Resultado = {resultado}")
finally:
    # Se ejecuta SIEMPRE, haya habido error o no
    print("Fin de la operación.")

Gestión de Archivos / Ficheros Nativos

Modos de apertura open(), cursor tell()/seek(), escritura y sentencia with open

La función nativa open(ruta, modo, encoding="utf-8") permite interactuar con archivos en disco. Se recomienda usar siempre encoding="utf-8" y el gestor de contexto with open para garantizar el cierre automático del fichero.

Modo Nombre Descripción / Comportamiento ¿Crea si no existe? ¿Borra previo? Posición Puntero
r Leer Solo lectura. Lanza FileNotFoundError si no existe. No No Al inicio (0)
rb Lectura Binaria Solo lectura de archivos en formato binario. No No Al inicio (0)
w Escribir Solo escritura. Sobrescribe todo si existe; lo crea si no. Sí Sí Al inicio (0)
wb Escritura Binaria Solo escritura en formato binario. Sobrescribe. Sí Sí Al inicio (0)
a Anexar (Append) Modo añadir contenido. Escribe al final sin borrar lo previo. Sí No Al final
r+ Mixto estándar Lectura y escritura combinadas sobre archivo existente. No No Al inicio (0)
w+ Mixto escritura Escritura y lectura. Sobrescribe el contenido previo. Sí Sí Al inicio (0)
a+ Mixto anexar Añadido y lectura. Crea el archivo si no existe. Sí No Al final
ficheros_nativos.py 
# Escritura con diferentes métodos
with open("datos.txt", "w", encoding="utf-8") as f:
    f.write("Prueba 1\n")                         # No introduce saltos automáticos
    print("Prueba 2", file=f)                   # Redirección de print()
    f.writelines(["Prueba 3\n", "Prueba 4\n"])  # Inyecta lista de textos
    print(f.name, f.mode, f.encoding, f.closed) # Propiedades del objeto fichero

# Lectura eficiente y control de cursor (tell / seek)
try:
    with open("datos.txt", "r", encoding="utf-8") as f:
        print(f.read(4))      # Lee los primeros 4 caracteres
        print(f.tell())       # Posición numérica exacta del cursor
        f.seek(0)             # Reubica el puntero al inicio absoluto (0)
        for linea in f:       # Recorrido línea a línea sin saturar RAM
            print(linea.strip())
except FileNotFoundError:
    print("Error: El archivo no se encontró.")

Archivos Estructurados: Formato CSV

Módulo nativo csv, csv.reader(), writerow(), writerows() y newline=""

El formato CSV (Comma-Separated Values) representa datos tabulares sencillos en texto plano. Para gestionarlos correctamente, Python incluye de manera nativa el módulo csv, mapeando filas como listas de cadenas.

gestion_csv.py 
import csv

# 1. LECTURA DE ARCHIVOS CSV
with open("ejemplo1.csv", "r", encoding="utf-8") as fichero:
    contenido = csv.reader(fichero, quotechar='"')
    # Opción A: Convertir todo directamente a una lista de listas
    datos = list(contenido)
    print(datos[0][0])  # Acceso directo a Fila 0, Columna 0

# 2. ESCRITURA DE ARCHIVOS CSV (newline="" evita filas vacías intermedias)
with open("ejemplo3.csv", "w", newline="", encoding="utf-8") as fichero:
    escritor = csv.writer(fichero)
    # Escribe una única fila
    escritor.writerow(['4/5/2015 13:34', 'Apples', '73'])
    # Escribe múltiples filas consecutivas
    escritor.writerows([
        ['4/5/2015 3:41', 'Cherries', '85'],
        ['4/6/2015 12:46', 'Pears', '14']
    ])

import json

# 1. LECTURA DE ESTRUCTURAS JSON

datos = json.loads(datos_json)
