3. Tipografía, Cajas de Aviso y Clases de Utilidad

3.1. Cajas de Aviso y Fondos (.box-card, .box-notice, .box-gray) ¶

Aviso Importante (.box-notice): Caja destacada con fondo gris claro y borde izquierdo azul primario para notas o recordatorios clave.

Tarjeta con Fondo Gris (.box-card.box-gray + .heading-compact)

Combina el borde y espaciado de .box-card con el fondo de .box-gray.

3.2. Etiquetas y Utilidades de Texto ¶

  • Etiqueta informativa: .label-info o .tag.label-info
  • Enlace principal destacado: Enlace con .link-primary
  • Enlace secundario / desactivado: Enlace con .link-muted
  • Texto azul pequeño: Texto con clase .text-small-blue (14px, azul)
  • Texto de peligro / alerta: Texto con clase .text-danger (rojo)
  • Texto de peligro en negrita: Texto con clase .text-danger-strong (rojo y negrita)
  • Código en línea dentro de párrafo o lista: p code y li code
4. Bloques de Código (.code-wrapper y .copy-btn)

4.1. Bloque de Código con Botón de Copiado ¶

El contenedor .code-wrapper incluye un botón .copy-btn conectado a la función copyCode(this) definida en script.js: 

#!/usr/bin/env python3
# Ejemplo de bloque de código con .code-wrapper y .copy-btn

def verificar_servicio(nombre_servicio, activo=True):
    Estado = "OPERATIVO" if activo else "CAÍDO"
    print(f"[{nombre_servicio.upper()}] Estado actual: {Estado}")

if __name__ == "__main__":
    verificar_servicio("nginx", activo=True)
