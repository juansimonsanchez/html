UT 2 - PROGRAMACIÓN ESTRUCTURADA

Ficha Técnica
Unidad de Trabajo UT2: Programación estructurada
Resultado de Aprendizaje Asociado RA2: Maneja los elementos necesarios en un lenguaje de programación, identificando los bloques fundamentales de construcción de un programa.
Criterios de Evaluación

CE2.a: Se ha identificado y operado adecuadamente con los diferentes tipos de datos en un programa.

CE2.b: Se han escrito programas estructurados que recojan, procesen y generen información correctamente.

CE2.c: Se han utilizado estructuras de control de flujo adecuadas en función del problema a resolver.

CE2.d: Se han aplicado técnicas de depuración y pruebas para asegurar la corrección de los programas.
Tiempo Estimado 2 horas (120 minutos)
Herramientas Visual Studio Code, Python 3, GNU/Linux
Objetivos Aplicar secuencialidad, operadores de sistemas, estructuras condicionales, bucles de control y modularización por funciones.
1. Descripción General

Esta prueba práctica está orientada a consolidar los contenidos teóricos y prácticos de la UT2. El alumnado resolverá problemas típicos de administración de sistemas y redes aplicando sintaxis rigurosa, validaciones de entrada, control de flujo y buenas prácticas de modularización.

2. Actividades

Actividades

Bloque 1: Secuencialidad y Cálculos de Sistemas

  1. Cálculo de Ancho de Banda Libre: Diseña un script que solicite al usuario la velocidad de línea contratada en Mbps y el porcentaje actual de uso de la red. El programa debe calcular y mostrar mediante un print formateado cuántos Mbps están ocupados y cuántos Mbps libres quedan disponibles en el enlace.
  2. Escribe un script que reciba una cadena de texto que representa el nombre completo de un archivo subido por un usuario (por ejemplo, informe_financiero_2026.pdf). El programa debe extraer su extensión (el texto posterior al último punto), convertirla automáticamente a minúsculas y comprobar si está permitida dentro de una lista blanca de formatos válidos (['pdf', 'docx', 'xlsx', 'txt']). El script debe mostrar por pantalla el nombre del archivo, la extensión detectada y un mensaje de texto indicando si el tipo de archivo que es (por ejemplo: El archivo es un documento pdf).

Bloque 2: Estructuras Condicionales y Validación

  1. Validador de Códigos de Estado HTTP: Crea un script que solicite un código de respuesta numérica HTTP. Mediante una estructura condicional múltiple (if - elif - else), el programa debe emitir un diagnóstico técnico adaptado:
    • 200: "OK - Servidor operativo"
    • 301 o 302: "Redirección detectada"
    • 400 a 499: "Error de cliente (Client Error)"
    • 500 o superior: "Error crítico del servidor (Server Error)"
    • Cualquier otro: "Código no reconocido"

Bloque 3: Modularidad, Funciones y Estructura Main

  1. Define una función llamada comprobar_permiso(rol_usuario, nivel_critico) que reciba dos parámetros: rol_usuario: una cadena que puede ser 'alumno', 'profesor' o 'administrador'. nivel_critico: un número entero del 1 al 5 que indica el nivel de seguridad del recurso solicitado. La función debe retornar True si el usuario tiene autorización según las siguientes reglas, o False en caso contrario: Los alumnos solo pueden acceder a recursos con nivel crítico menor o igual a 2. Los profesores pueden acceder a recursos con nivel crítico menor o igual a 4. Los administradores tienen acceso total a cualquier nivel (1 a 5). El programa principal debe solicitar repetidamente el rol y el nivel de seguridad al usuario, comprobando el acceso mediante la función, hasta que se introduzca la palabra 'salir' como rol para finalizar la ejecución.
  2. Calculadora de Nómina con Retorno Múltiple: Escribe una función llamada calcular_neto_empleado(salario_base, ventas) que compute las comisiones de un técnico sabiendo que cada venta realizada aporta un 5% extra sobre el sueldo base. La función debe devolver de forma simultánea tres valores: el salario base, la comisión total calculada y el sueldo bruto final a percibir. Desempaqueta estos valores en el programa principal y preséntalos formateados en pantalla.
