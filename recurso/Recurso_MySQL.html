DESPLIEGUE DE MYSQL ¶

El estándar de la industria moderna prioriza entornos inmutables y reproducibles frente a las tradicionales instalaciones locales sobre sistemas hosts de desarrollo (bare-metal). Utilizar Docker y Docker Compose asegura que todo el alumnado trabaje en un entorno idéntico. Con este recurso aprenderas a realizar la instalación de MySQL o utilizar MySQL con contenedores Docker

Instalación de MySQL en Ubuntu ¶

Paso 1: Actualizar el repositorio e instalar MySQL Server ¶

Ejecuta el gestor de paquetes apt para instalar la versión oficial incluida en los repositorios de Ubuntu:

sudo apt update
sudo apt install -y mysql-server
Paso 2: Verificar que el servicio esté activo

Una vez finalizada la instalación, verifica que el motor de la base de datos esté ejecutándose correctamente:

sudo systemctl status mysql
Deberías ver el estado en verde como active (running).

Paso 3: Configurar la seguridad inicial (mysql_secure_installation)

Ejecuta el script de seguridad integrado para establecer reglas básicas (como cambiar la política de contraseñas y eliminar usuarios anónimos):

sudo mysql_secure_installation
El asistente te hará las siguientes preguntas:

  1. VALIDATE PASSWORD COMPONENT: Presiona y si deseas exigir contraseñas complejas, o n si prefieres contraseñas sencillas para entornos de desarrollo.

  2. Set root password: Define una contraseña para el usuario root de MySQL.

  3. Remove anonymous users?: Responde y (elimina usuarios anónimos).

  4. Disallow root login remotely?: Responde y (por seguridad, se limita a root a conectarse solo localmente) y n en caso contrario

  5. Remove test database and access to it?: Responde y (elimina la base de datos de prueba) y n en caso contrario

  6. Reload privilege tables now?: Responde y (aplica los cambios inmediatamente).

Paso 4: Cambiar la autenticación del usuario root (Opcional pero recomendado)

En Ubuntu, el usuario root de MySQL usa por defecto el plugin auth_socket, lo que exige usar sudo mysql para entrar. Si prefieres acceder mediante usuario y contraseña tradicionales (por ejemplo, desde un cliente gráfico como DBeaver o Workbench):

  1. Accede a la consola de MySQL:

sudo mysql
Cambia el método de autenticación y asigna una contraseña ejecutando la siguiente consulta SQL (reemplaza TuPasswordSegura123! por tu clave):

ALTER USER 'root'@'localhost' IDENTIFIED WITH caching_sha2_password
BY 'TuPasswordSegura123!';
FLUSH PRIVILEGES;
EXIT;
Cuidado para no tener problema y poder acceder desde cualquier equipo establecer como método de autenticación mysql_native_password

ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password
BY 'TuPasswordSegura123!';
FLUSH PRIVILEGES;
EXIT;
Paso 5: Comprobar el acceso local

Ahora puedes iniciar sesión en MySQL con tu usuario y contraseña mediante el cliente local:

mysql -u root -p

Uso de MySQL con Docker y Docker Componse ¶

Versión avanzada 1 (2º ASIR - UT1) ¶

Este archivo monta los directorios críticos de configuración, datos y logs sobre el volumen físico local para permitir un análisis interactivo sin perder persistencia.

version: '3.8'
services:
db:
image: mysql:8.0
container_name: mysql-sysadmin-ut1
restart: always
command: --default-authentication-plugin=mysql_native_password
environment:
MYSQL_ROOT_PASSWORD: RootPass_2026
MYSQL_DATABASE: sysadmin_audit
ports:
- "3306:3306"
volumes:
# Persistencia del directorio de datos del motor
- db_data:/var/lib/mysql
# Mapeo personalizado para aplicar configuraciones
(/etc/mysql/conf.d/)
- ./config:/etc/mysql/conf.d
# Directorio de Logs mapeado para permitir análisis externo directo
en el host
- ./logs:/var/log/mysql
networks:
- asir-net
deploy:
resources:
limits:
cpus: '1.5'
memory: 1500M
volumes:
db_data:
networks:
asir-net:
driver: bridge

# Iniciar contenedor
docker compose up -d
# Detener contenedor
docker compose down -v
# Comprobar contenedores activos
docker ps
# Reiniciar contenedor tras cambios de configuración
docker compose restart
# Entrar al contenedor
docker exec -it mysql-sysadmin-ut1 bash
# Ejecutar MySQL
mysql -u root -p -P 3306
Si no tenemos instalado MySQL en el servidor necesitaremos un cliente:

sudo apt install mysql-client-core-8.0
# El acceso en este caso será con:
mysql -u root -p -h 127.0.0.1 -P 3306
