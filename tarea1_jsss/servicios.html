Guía de Instalación del Servidor Apache en GNU/Linux

  1. Actualización de los repositorios del sistema operativo:
    • Comando: sudo apt update && sudo apt upgrade -y
    • Verificación: /var/log/apt/history.log
  2. Instalación del paquete base y módulos necesarios:
    • Comando: sudo apt install apache2 apache2-utils -y
  3. Configuración del sitio web virtual (Virtual Host):
    • Ruta de configuración: /etc/apache2/sites-available/departamento.conf
    • Ruta raíz de documentos (DocumentRoot): /var/www/departamento
    • Activación del sitio: sudo a2ensite departamento.conf
  4. Reinicio y validación del demonio:
    • Comando: sudo systemctl restart apache2
    • Comprobación de estado: sudo systemctl status apache2
